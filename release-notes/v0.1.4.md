# Lumen RT 0.1.4 — Early Alpha Development Update

> **Experimental early alpha:** This build is released while development is ongoing. New features have not been fully tested. Some features that worked in earlier builds may regress. Expect possible lighting instability, visual artifacts, FPS drops, crashes, or mod-compatibility issues.

## Experimental Upscaling and Denoising

- Added **AMD FSR Super Resolution (FSR SR)** support.
- Added **AMD FSR Frame Generation (FSR FG)** support.
- Added **NVIDIA Real-Time Denoisers (NRD)** support.
- These features are experimental and may not be fully stable.

## Experimental Lighting: ReSTIR and SHARC

- Added **ReSTIR** (Reservoir-based Spatiotemporal Importance Resampling) and **SHARC** (Spatially Hashed Radiance Cache).
- These systems aim to improve lighting quality and temporal stability, but flickering, incorrect lighting, artifacts, and performance issues are still possible.

## Experimental Mod Compatibility

- **Physics Mod:** Improved ray-traced rendering of block fragments, physics particles, mob ragdolls, and other simulation effects. Powerful hardware is recommended; visual or performance issues remain possible.
- **Grassier Grass:** Added support for custom grass geometry and wind-driven shader animation in the ray-traced scene. Grass may still disappear or animate incorrectly in some conditions.
- **Spatial GUI:** Added support for world-space 3D inventory and storage UI planes, including first-person and third-person views. Rendering issues may still occur.

These mods have been tested, but full compatibility is not guaranteed. Most other mods have not been tested.

## Fixes and Rendering Improvements

- Added compatibility fixes involving **Lumen RT, Iris, and Sodium**.
- Fixed incorrect vanilla player shadows when using **First Person Model**.
- Improved real-time world-geometry shadows on First Person Model characters and **RT Hand**.
- Added a fix for the First Person Model character disappearing when **F1** is pressed.
- Addressed occasional vanilla player-model deformation and animation stutter.
- Fixed water becoming dark at certain view angles.
- Significantly reduced excessive blur when looking through glass, though it may still occur.
- Improved exposure, tone mapping, and overall image quality.
- Fixed excessive red tint and blown-out colors in the Nether.

## New Controls and Visual Features

- Added **GGX Scale** in TOML configuration for reflection sharpness and blur.
- Added **POM quality** and **parallax** controls. Parallax is disabled by default for performance.
- Improved water rendering with Minecraft's vanilla water texture, stronger depth-dependent light absorption, and a more pronounced blue tint.
- Replaced the blank resource-pack-change screen with a loading progress bar.
- Added experimental **VRAM caching of prebuilt texture atlases** for faster transitions into ray-tracing mode. Effectiveness depends on available VRAM.

## Important Notes

- This is not a stable release. Rendering features, compatibility, and performance may change.
- Some custom mod shaders are compiled in the background by `slangc.exe`. Their effects may appear after a delay of a minute or longer; compiled shaders are cached when possible.
- If FPS drops suddenly and remains low, toggling ray tracing off and back on may temporarily help.
- Check the release's **Assets** section for the actual JAR. This page alone does not mean that a binary has been uploaded.
- GitHub availability does **not** imply that CurseForge has completed review.
