# Lumen RT — Official Releases

This is the official GitHub release archive for **Lumen RT** (formerly **AetherRT**), an experimental hardware ray-tracing mod for Minecraft Java Edition.

> **Early Alpha:** Lumen RT is under active development. Visual artifacts, unexpected behavior, crashes, compatibility issues, and performance regressions may occur. Back up important worlds before testing.

## Downloads

**[Download Lumen RT from GitHub Releases](https://github.com/rmiss1/LumenRT-Releases/releases)**

Compiled JAR files are distributed as **release assets**. Select the version you need and download its JAR under **Assets**. A release without a JAR asset is a placeholder and is not yet available to download from GitHub.

**[CurseForge project](https://www.curseforge.com/minecraft/mc-mods/lumenrt)** · **[Release history](CHANGELOG.md)**

## Installation

1. Choose a version compatible with your Minecraft version and mod loader.
2. Read the requirements, known issues, and installation instructions for that version.
3. Download the official JAR from its release's **Assets** section.
4. Follow the installation instructions for the selected version.

Older builds may have different hardware and dependency requirements. For the published 0.1.x CurseForge builds, the target is **Minecraft Java Edition 26.3 / Fabric**.

## GitHub releases and CurseForge

Some experimental builds may be published on GitHub while the corresponding CurseForge upload is still awaiting review. **A GitHub release does not indicate CurseForge approval.**
